GOOD TO KNOW

Frequently asked questions.

Do I need an account?

No. You can start scoring locally. An account is optional and enables cloud synchronization.

Can I scan a scoreboard with several bowlers?

Yes. Photograph the screen and select your own row. Review the results before saving, as recognition can make mistakes.

Can I use BowlBoard on my iPhone?

Yes, you can use the web app in Safari and add it to your Home Screen. An App Store release is planned, but not yet available.

Is BowlBoard free?

Yes, it is free to start. Optional premium features are planned; no paid plan is currently being offered.

What if I need help?

Visit Support for help with scores, account sync, or other questions.
